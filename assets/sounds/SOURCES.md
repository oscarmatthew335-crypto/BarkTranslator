# Sound sources

Speak tab sounds are cut from real recordings on BigSoundBank
(https://bigsoundbank.com), released under CC0 (public domain): free for
commercial use, no attribution required. Built with `tools/make_real_sounds.py`,
which lists which recording and which seconds each sound uses.

Recordings used (BigSoundBank sound numbers): 0098, 0390, 0436, 0682, 0879,
1060, 1544, 1886, 1891, 1894, 1896, 1898, 1900, 2352, 2450, 2451, 2954.

The clicker, whistle, treat shake, "psst" and feather toy sounds are still
synthesized by `tools/make_sounds.py`.
